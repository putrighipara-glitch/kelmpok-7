SPLDV Calista Adilah (12)

Lihat Perhitungan

Permisalan


x = harga 1 robot
y = harga 1 hiasan dinding

Persamaan


2x + y = 165.000
3x + 2y = 285.000

Penyelesaian


eliminasi variabel y
2x + y = 165.000 | ×2
3x + 2y = 285.000 | ×1
4x + 2y = 330.000
3x + 2y = 285.000
------------------- - x = 45.000
subtitusi nilai x
2x + y = 165.000
2(45.000) + y = 165.000
90.000 + y = 165.000
y = 165.000 - 90.000
y = 75.000
Jadi:
Harga 1 Robot = 45.000
Harga 1 Hiasan Dinding = 75.000

SPLDV GHifara Anindya Putri (17)

Lihat Perhitungan Permisalan

x = Harga 1 Lampu Hias
y = Harga 1 Pixel Art

Persamaan

x + y = 95.000
x + 2y = 140.000

Penyelesaian

eliminasi variabel y
x + y = 95.000 | ×2
x + 2y = 140.000 | ×1
x + 2y = 190.000
x + 2y = 140.000
------------------- -
x = 50.000
subtitusi nilai x
x + y = 95.000
50.000 + y = 95.000
y = 95.000 - 50.000
y = 45.000
Jadi:
1 Lampu Tidur = Rp50.000
1 Hiasan Dinding Pixel Art = Rp45.000
